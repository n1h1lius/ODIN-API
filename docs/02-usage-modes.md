# Usage Modes

ODINN API currently exposes two main usage modes:

- **Legacy Mode** — simple, language-based access
- **Advanced Mode** — author-based (and later edition-based) access

## Legacy Mode

Legacy Mode is designed for:

- Quick access
- Simple clients
- Minimal metadata

See: [Legacy Mode](02.1-legacy-mode.md)

## Advanced Mode

Advanced Mode is designed for:

- Author-specific queries
- Future edition-based queries
- Richer metadata

See: [Advanced Mode](02.2-advanced-mode.md)

## Metadata Mode (planned)

A future mode focused on:

- Authors
- Editions
- Manuscripts
- Cross-book relationships

See: [Metadata Mode](02.3-metadata-mode.md)
