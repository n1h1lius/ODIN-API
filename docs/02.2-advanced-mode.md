# Advanced Mode

Advanced Mode focuses on **authors** (and later editions).

Current pattern (author-based):

`/advanced/{book}/author/{author}/{action}`

### Example (Jackson Crawford, Hávamál)

```text
/advanced/havamal/author/jackson_crawford/random
/advanced/havamal/author/jackson_crawford/all
/advanced/havamal/author/jackson_crawford/stanza/1
/advanced/havamal/author/jackson_crawford/search?word=guest
/advanced/havamal/author/jackson_crawford/from/1/to/10
```

### Normalization

Author keys are normalized:

* Lowercase

* Spaces and hyphens → _

* Accents removed

### Example:

* "Jackson Crawford" → jackson_crawford

* "Ólafur Eliasson" → olafur_eliasson

### Data model

Advanced entries use a richer structure:

```json

{
  "book": "Hávamál",
  "language": "English",
  "translator": "Jackson Crawford",
  "translator_year": 2015,
  "source": "Codex Regius",
  "original_year": "ca. 1200",
  "stanzas": [
    { "id": 1, "stanza": "...", "notes": null },
    { "id": 2, "stanza": "...", "notes": null }
  ]
}

```
